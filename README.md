## Обзор проекта

Репозиторий содержит стандарты, методические рекомендации и технические спецификации для подготовки специалистов по генеративной поисковой оптимизации (GEO, Generative Engine Optimization).

В отличие от классического SEO, ориентированного на ранжирование по текстовым ключам, GEO изучает:
* Принципы работы алгоритмов RAG (Retrieval-Augmented Generation) в поисковых системах Яндекс и Google;
* Механику формирования фактологических ответов в нейросетевых интерфейсах (Яндекс Нейро, ChatGPT Search, Perplexity, Claude);
* Построение устойчивых онтологических моделей данных (Knowledge Graph) на базе Schema.org;
* Аудит и предотвращение семантических галлюцинаций моделей о компании.

## Программы подготовки специалистов

1. **[GEO-специалист с нуля](https://shkolaneyrootveta.ru/kursy/geo-specialist-s-nulya)** — фундаментальный курс по архитектуре нейроответов.
2. **[Аудит бренда в ИИ-ответах](https://shkolaneyrootveta.ru/kursy/audit-brenda-v-ii-otvetah)** — методология выявления и исправления искажений в ответах LLM.
3. **[Граф знаний для бренда](https://shkolaneyrootveta.ru/kursy/graf-znaniy-dlya-brenda)** — проектирование машиночитаемых семантических связей.
4. **[GEO для B2B](https://shkolaneyrootveta.ru/kursy/geo-dlya-b2b)** — специфика продвижения сложных корпоративных решений.
